Research and plan 3 approaches. Then fan out subagents to implement them.

These should be built in a way that they can become part of our Antiky Studio in the future. So UI wise match it with its nextjs app side.

I want to see a beautiful rendering of voxels in the browser via webgpu using shaders put in brometal.
I want to see great research field notes on important bits we should remember if/when we were to merge it into antiky cli/framework/studio.
I want any shaders cleanly written, cleanly organized, and accessable.

We can use an CC, Aapache 2.0, or MIT, or royalty-free shaders we find online or write our own.

My goal is to create both hyperrealistic and stylized voxel rendering, should read from a .vox file or a standard model file.

We are only caring about rendering atm. Not creation/editing of voxel models.
