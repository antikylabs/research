Interpretation order

Gate first. Measurement second. Claim last.

  1. Scene/task: confirm that the intended workload dimensions match.
  2. Topology/artifact: identify whether GPU work or generated shaders differ.
  3. Attribution: make only the claim supported by the gates above.

Descriptor-derived bytes are not physical VRAM. Chrome GPU-process time is not shader-core occupancy. API payload volume is not physical bus traffic, and a one-way upload is not a CPU↔GPU round trip.
